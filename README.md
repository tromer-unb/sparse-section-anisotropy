# Sparse-section anisotropy

Research code for **direct inference of a 3D pore-space correlation tensor from sparse, oriented 2D sections**.

This repository accompanies the manuscript *Beyond 2D-to-3D Reconstruction: Direct Inference of Pore-Space Anisotropy from Sparse Sections*.

## What the method does

For an in-plane direction `u`, a directional correlation length `ell(u)` is measured from the first `1/e` crossing of the finite-domain two-point autocorrelation. Measurements from multiple oriented sections are mapped into a common 3D frame and fitted to

```text
ell(v)^(-2) = v^T Q v
```

where `Q` is a symmetric positive-definite 3 x 3 tensor. Its eigenvectors define principal structural directions and its eigenvalues define the associated correlation scales.

**Important:** this code does **not** reconstruct an unobserved 3D voxelized pore geometry. It reconstructs a lower-dimensional 3D structural descriptor (the correlation-length tensor) directly from 2D measurements.

## Quick start

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install -e ".[dev]"
pytest -q
```

To apply the method to your own oriented binary 2D rock sections:

```bash
ssa-infer examples/sections_manifest.example.json --output tensor_result.json
```

Each section must be accompanied by a 3 x 2 orthonormal basis `B` whose columns describe the two image axes in the common 3D coordinate system. See [docs/scientific_scope.md](docs/scientific_scope.md) and [examples/sections_manifest.example.json](examples/sections_manifest.example.json).

## Reproducibility policy

The repository separates:

1. **paper-frozen scripts**, preserved to audit the calculations that produced the manuscript;
2. **processed outputs**, which allow reported summary statistics to be independently recomputed without repeating expensive 3D Monte Carlo reference calculations; and
3. **a reusable package**, written after the analysis to expose the core method with tests and a stable input format.

The reusable package is not used retroactively to claim that the manuscript figures were generated by refactored code. The frozen scripts remain the computational record for the paper.
