# Data directory

This repository intentionally separates **source data provenance** from **derived audit tables**.

- `provenance/real_rocks.json`: machine-readable identities for the two upstream ROI-1 files used in the real-rock validation.
- `processed/`: compact CSV outputs generated by the frozen paper scripts.
- raw `.raw`, `.raw.tar.bz2`, and computational cache directories are ignored by Git.

The authoritative real-rock source volumes remain on Figshare+. See [../docs/data_provenance.md](../docs/data_provenance.md).
